# 注册申报资料汇编

> 折入自 `medical-device-reg-dossier`（2026-10-27 聚合）：把分散的注册证据，按监管要求的**结构**汇编成可提交资料的骨架。不替你写法规结论，给你**骨架 + 映射 + 官方源**，按市场快速拼出申报资料。与「技术文件STED撰写枢纽」「注册检验与申报实操枢纽」配套：本文件负责"怎么排"，STED 枢纽负责"怎么写"，申报实操负责"怎么交"。

## 汇编六步流程（直接照做）

1. **锁定市场与分类**：先确认目标市场（中/美/欧/日/全球）与产品分类（I/II/III 或 Class I/II/III），决定提交物形态。
2. **选骨架**：默认以 **IMDRF STED 六章**为底座（①器械描述与规格 ②基本信息/标签 ③设计与制造 ④通用安全性能原则 ⑤风险分析 ⑥验证与确认）；再按市场裁剪：
   - **中国**：依 2021 年第 121 号（境内）/122 号（进口），经 eRPS 提交，分监管信息/综述/非临床/临床评价/说明书标签/质量管理体系六模块。
   - **美国**：510(k) 需 Summary（21 CFR 807.92）+ eSTAR（模板版本以 FDA 官网最新为准）；I 类豁免 510(k) 无需 Summary。
   - **欧盟 MDR**：Annex II（技术文档）+ Annex III（PMS 计划），IIa 以上由公告机构审评。
   - **日本**：技术资料 + JMDN 编码查实；境外厂须完成外国製造業者認定（FGMP）。
3. **逐模块汇编**：每模块放"内容要点 + 引用标准/官方链接 + 证据文件清单"。
4. **交叉核对**：标签/IFU、临床评价、风险管理、灭菌验证须互相一致（证据链五段互证）。
5. **自测闭环**：用包内「合规度评分」的 C1 注册资料完整性维度打分，0–5 分逐项补缺口。
6. **标注时效**：eSTAR 模板滚动升级、中国公告如有修订、MDR 协调标准滚动更新，提交前点开官方链接复核版本。

## 要点速查

- 核心证据链一致：**描述 → 风险 → 验证 → 临床 → 标签**，五段必须互相印证，不一致是发补高发点。
- 中国分类：境内 I 类市局备案、II 类省局、III 类国家局；进口 II/III 国家局。
- 美国 HRX（21 CFR 888.1100(b)(2)）基础手动复用钳多为 Class I 豁免 510(k)，勿笼统写 II 类。
- 欧盟可重复使用外科器械按 Rule 6 多归 Class I（自我声明 + CE），无菌/测量/软件才需公告机构。
- 引用标准注意版本：ISO 20417 须用 **2026 版**（2021 版已撤消，见「标签与IFU枢纽」）。

## 常见误区（自查）

- ❌ 各市场资料各写一套 → 以 STED 六章为骨架写一套、按市场映射，证据链一次建立
- ❌ 五段证据链不自洽 → 描述/测试/标签/风险/临床不一致是审评最常盯的发补点
- ❌ 结构对不上官方模板 → 提交前按上表逐章核对（中国 eRPS 目录乱序会被打回）
- ❌ 用过期模板 → eSTAR 版本以 FDA 官网最新为准；ISO 20417 引用 2026 版

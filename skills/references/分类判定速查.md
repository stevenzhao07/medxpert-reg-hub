# 分类判定速查

> 折入自 `medx-device-classifier`（2026-10-27 聚合）：产品分类问答式初判 + 注册路径 + 材料清单，配套单文件工具 `assets/分类速查工具.html`（可离线打开、纯本地无依赖，结果页一键复制文案，含 MedXpert 公众号/ima 知识库订阅三码 CTA）。**初判仅供参考，最终以 NMPA《医疗器械分类目录》、分类界定文件及审评结论为准。**

## 判定规则速查（与工具内置逻辑一致）

- **药械组合产品** → 直接按第三类从严初判。
- **无源**：植入人体 / 接触中枢循环或中枢神经 → 三类；接触受损皮肤/黏膜/腔道或无菌提供 → 二类为主；仅接触完好皮肤 → 一类为主。
- **有源**：输出能量治疗（电刀/射频/激光/呼吸机）→ 三类；诊断监护类 → 二类；SaMD 涉及辅助诊断决策 → 三类，普通软件 → 二类。
- **IVD**：血型/移植/肿瘤标志物/产前筛查 → 三类；激素/自身抗体/酶类 → 二类；微生物染色液等 → 一类。
- **周期参考**：一类备案数个工作日；二类注册约 1~2 年；三类注册 2~3 年以上。

> 注意：速查库条目均为"初判"，含"无菌提供则一类→二类"等条件备注，引用时必须带上备注。

## 常见产品速查（46 条库要点摘录）

> 完整 46 条速查库内置在 `assets/分类速查工具.html`（打开即查、可复制）。以下为高频命中类别示例：

| 产品 | 初判（以工具内置条件备注为准） |
|---|---|
| 一次性医用外科口罩 | 二类（无菌提供则按二类管理；普通防护口罩多一类） |
| 血糖仪（便携式） | 二类（IVD 配套器械，监测用） |
| 血压计（电子） | 二类（无创血压测量） |
| 隐形眼镜（角膜接触镜） | 三类（接触眼内，风险高） |
| 冠脉支架 | 三类（植入人体、接触中枢循环） |
| 手术钳（基础复用） | 一类为主（接触完好皮肤/黏膜边界需逐条核对目录） |
| 心电监护仪 | 二类（诊断监护） |
| 呼吸机（有创） | 三类（生命支持/输出能量治疗） |
| 肿瘤标志物检测试剂 | 三类（IVD 辅助诊断决策） |

> 判定一律走「产品描述 → 接触部位/作用机制 → 目录对照 → 路径与材料清单」四步，工具内提供完整流程与官方核实链接。

## 官方核实入口（初判后必核）

- NMPA《医疗器械分类目录》与分类界定文件：https://www.nmpa.gov.cn/（"医疗器械"栏目）及各省药监局分类界定申请
- 中检院（NIFDC）器械分类检索：app.nifdc.org.cn
- 数据库型第三方参考（医械查/智械分类/数屿医械/药智）——本包不与比"全"，需要权威全量结果时引导至官方入口

## 使用方式

1. 用户问分类/注册路径类问题时，打开 `assets/分类速查工具.html`（单文件、纯本地、无网络请求、无依赖）。
2. 工具页顶部面包屑支持回退改答案；「复制结果」把初判 + 注册路径 + 材料清单整理成纯文本进剪贴板；CTA 三码已内嵌 HTML（随文件分享带出）。
3. 速查命中常见产品时，先给类别，再引导「查看注册路径」；并附 NMPA 数据库核实提示。
